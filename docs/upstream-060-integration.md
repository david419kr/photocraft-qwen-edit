## 반영 범위

원본 커밋을 일부 골라 복사하는 대신 전체 main 이력을 병합한다. 원본 변경을 빠뜨리거나
서로 의존하는 수정의 일부만 가져오는 문제를 피하고, 기존 개인 기능은 유지한다.

대표적인 원본 개선:

- 파일: OpenRaster 읽기/쓰기, Paint.NET 레이어 읽기, Affinity 가져오기,
  RAW/DNG 디코더 확장, PSD 블록·레이어·알파 채널 및 TIFF 저장 개선.
- 편집: 추가 도구, 선택 영역 알고리즘·성능, 자유 변형·워프·자르기,
  레이어 복제/정렬·잠금·Background 처리 개선.
- 필터/합성: 다양한 필터의 계산·미리 보기·속도와 블렌딩·효과 수정.
- UI: 숫자 정밀도·산술 입력·Tab 이동·팝업 슬라이더, 메뉴·도킹·색상 패널,
  문서 전환/탭 닫기, 텍스트와 클립보드 입력 개선.
- 자동화/품질: `ui.set` 원자적 검증, 제어 옵션 추가, 테스트·코퍼스·문서 갱신.

모든 개선의 픽셀 결과나 모든 장비/파일 형식을 이번에 개별 확인했다는 뜻은 아니다.

## 기존 기능과 겹친 부분

다음은 같은 위치를 수정했거나 자동 병합만으로는 동작을 보존할 수 없었던 부분이다.

### 동작상 알아둘 차이

- 통합 당시에는 Metadata: None에서도 AI 프롬프트를 보존했으나, 후속 요청으로 이 예외를
  폐기했다. 현재 None은 AI 기록도 제거하고 PNG 알파 LSB도 정리한다. [현재 동작](comfyui.md)을 참조한다.
- 원본에 새로 추가된 도구/명령은 기존 한국어 목록에 없던 경우 원본 번역 또는 영어
  fallback을 사용한다. 기존 작업 내역 번역과 프롬프트 복사 UI는 유지한다.
- **새 OpenRaster(.ora) 저장은 프롬프트 기록을 보존하지 않는다.** 원본 ORA 저장기가
  XMP/EXIF/일반 텍스트를 저장하지 않으며, 저장 시 메타데이터 누락 경고를 표시한다.
  이번에는 비표준 ORA 확장을 추가하지 않았다. AI 기록이 필요하면 기존 PNG/JPEG/WebP/
  TIFF/AVIF/PSD/`.pcraft` 형식을 사용한다. 새 읽기 전용 PDN/Affinity/RAW 가져오기에는
  ComfyUI 편집을 적용할 수 있고 결과를 기존 지원 형식에 저장할 수 있다.
- 파일 형식/도구 증가로 메뉴 수와 버전 표시가 달라진다. ComfyUI 워크플로우,
  프롬프팅, 모델 선택/기억, 번역 Default 스타일, 기본 25/8 스텝·CFG 1.0은 변경하지 않는다.
